# DermaClass-AI

An AI-powered skin condition image classification research project using deep learning and a responsive web application.

## Project Objectives

- Classify selected common skin conditions from images.
- Explore transfer learning for image classification.
- Evaluate model performance using appropriate metrics.
- Use Grad-CAM for model explainability.
- Provide an interactive web application for educational demonstration.

## Current Dataset

Primary dataset: Skin Condition Image Network (SCIN).

Provisional classes:
- Contact dermatitis
- Eczema
- Psoriasis
- Tinea

Dataset preparation and research are documented in `notebooks/01_dataset_research.ipynb`.

## Technology Stack

- Python
- TensorFlow / Keras
- Pandas and NumPy
- Flask
- HTML, CSS and JavaScript
- Scikit-learn

## Project Status

Dataset research and initial preparation have been completed. Model training, evaluation, explainability and web application development are in progress.

## Important Disclaimer

This project is an educational research prototype. It is not a clinically validated diagnostic tool and must not be used as a substitute for professional medical evaluation.
